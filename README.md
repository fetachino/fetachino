## Featured project

### [Indy Geospatial Accessibility Platform](https://github.com/fetachino/indy-geospatial-accessibility-platform)

A recruiter-ready GIS portfolio project investigating which Marion County, Indiana block groups may have inadequate access to public transit and essential services. It includes reproducible public-data acquisition, validated PostGIS ETL, transparent accessibility analysis, a versioned FastAPI GeoJSON API, and an interactive React/MapLibre map.

**Stack:** Python · GeoPandas · PostGIS · FastAPI · React · TypeScript · MapLibre · Docker · GitHub Actions

The project documents optional ArcGIS Pro/Online workflows without claiming licensed execution or publication. Results are explicitly described as centroid-based straight-line proximity indicators, not walking access or policy recommendations.
